# Integer

A single `INT` value on its own wire. Set a step count, a size, or any other
whole number once and share it across every node that needs it.

## Controls

- **value**: The integer to output.

## Output

- **int**: The value, unchanged.

For arithmetic on the way — halving a size, adding a margin — feed this into
**Math Expression 🆎** instead of retyping derived numbers.
