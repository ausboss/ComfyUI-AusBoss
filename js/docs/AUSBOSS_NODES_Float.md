# Float

A single `FLOAT` value on its own wire. Share one strength, scale, or CFG
across several nodes and change it in one place.

## Controls

- **value**: The float to output.

## Output

- **float**: The value, unchanged.

For arithmetic on the way — scaling, clamping with `min`/`max` — feed this
into **Math Expression 🆎** instead of retyping derived numbers.
