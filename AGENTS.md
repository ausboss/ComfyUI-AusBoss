# ComfyUI-AusBoss: start here

A pack of ComfyUI custom nodes by ausboss. Two kinds of agents read this.

- **Using the nodes in a workflow?** Read
  [js/docs/agents/README.md](js/docs/agents/README.md): which node does which
  job, where each node's help page is, and the example workflows. That folder
  ships with the pack, so it is also in a ComfyUI install.
- **Changing the pack itself?** Read [CONTRIBUTING.md](CONTRIBUTING.md) in full
  before the first edit. It holds the layout, the rules every node follows and
  the checks to run. A new node follows
  [docs/adding_a_node.md](docs/adding_a_node.md).
